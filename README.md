# НЕФТЬ · Истории гостей

Рабочий прототип минималистичного сайта кофейни **НЕФТЬ** вокруг анимированной карусели
историй гостей. Посетитель смотрит истории и может отправить свою; история попадает
в общую карусель **только после публикации модератором**.

Стек: **Python 3 (только стандартная библиотека)** + HTML/CSS/JS без сборки и без зависимостей.
Данные хранятся на сервере в файле `data/db.json`, фотографии — в `data/uploads/`,
поэтому ничего не теряется при перезагрузке страницы и истории видны всем посетителям.

---

## Запуск

Нужен Python 3.9+ (проверено на 3.12).

```bash
cd d:\Projects\neft-stories
python server.py
```

Сервер напечатает в консоль две ссылки:

```
Главная страница : http://localhost:8000/
Модерация        : http://localhost:8000/moderation?key=<секретный-ключ>
```

* Публичная страница — `http://localhost:8000/`
* Секретная страница модерации — `http://localhost:8000/moderation?key=…`
  **Ссылки на неё нет нигде в публичном интерфейсе.** Без правильного ключа сервер
  отвечает `404`, поэтому страница не «светится».

Полезные опции:

```bash
python server.py --port 8080          # другой порт
python server.py --host 127.0.0.1     # слушать только локально
```

Свой ключ модерации можно задать заранее:

```powershell
$env:NEFT_MODERATION_KEY="моя-тайная-ссылка"; python server.py
```

Или на Windows просто двойным щелчком по `run.bat`.

## API

| Метод | Путь | Назначение |
|---|---|---|
| `GET`  | `/api/stories` | **только опубликованные** истории для карусели |
| `POST` | `/api/stories` | отправка новой истории (создаётся со статусом «на модерации») |
| `GET`  | `/api/moderation/stories` | все истории (нужен заголовок `X-Moderation-Key`) |
| `PATCH`| `/api/moderation/stories/{id}` | правка текста, фото и флага `published` (нужен ключ) |

Тело `POST /api/stories`:

```json
{ "text": "Текст истории (до 600 символов)", "photo": "data:image/jpeg;base64,…" }
```

`photo` необязателен, допускается ровно одна фотография (JPG/PNG/WEBP/GIF, до 5 МБ)
в виде data-URL. Сервер сам сохраняет файл в `data/uploads/`.

## Валидация

Проверяется и на клиенте, и на сервере:

* пустую историю отправить нельзя;
* текст ограничен **600 символами** (шкала лимита заполняется по мере ввода);
* можно приложить **только одну** фотографию, не более 5 МБ.

## Как проверить сценарий

1. Откройте главную — видна анимированная карусель (или подсказка, если историй ещё нет).
2. Нажмите **«Поделиться своей историей»**, введите текст и при желании приложите фото.
3. Отправьте — появится экран с сообщением про купон на бесплатный напиток.
   В карусели история пока **не появится**: она ушла на модерацию.
4. Откройте ссылку модерации из консоли сервера — история в списке.
5. Включите флажок **«Опубликовано»** — история появится в карусели на главной.
6. Снимите флажок — история снова скрыта. Кнопка **«Редактировать»** меняет текст и фото.

## Демо-данные

В папке `data/` уже лежат **3 опубликованные демо-истории с фотографиями**, чтобы
карусель была видна сразу после запуска. Ключ модерации хранится там же
(`data/db.json` → `settings.moderation_key`) и печатается в консоль при старте.

Начать с чистого листа: остановите сервер, удалите папку `data/` и запустите его снова —
база и новый ключ модерации создадутся автоматически.

## Заметки для продакшена

Это учебный прототип: без авторизации, без сжатия изображений и на встроенном
HTTP-сервере Python. В реальном проекте стоит заменить хранилище на SQLite/Postgres
(или Supabase), поставить нормальный WSGI/ASGI-сервер, добавить авторизацию модератора
и модерацию изображений.
